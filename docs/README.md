# OctoAcme Project Management Documentation

Welcome to OctoAcme's project management framework. This directory contains our standardized processes for running projects from initiation through retrospective and continuous improvement.

## Overview

OctoAcme uses a structured, phase-based approach to project management that emphasizes clear communication, data-driven decisions, and continuous improvement. Our framework ensures that projects are well-planned, properly tracked, and deliver measurable value to customers and the business.

**Core Principles:**
- **Customer-first:** Prioritize customer value and usability in all decisions
- **Iterative delivery:** Deliver small, testable increments rather than large batches
- **Clear ownership:** Each project has a named Project Manager and Product Lead
- **Data-informed decisions:** Measure impact and iterate based on evidence
- **Psychological safety:** Encourage feedback and learning across the team

## Quick Start

OctoAcme projects follow a five-phase lifecycle:

1. **Initiation** — Validate the business need, align stakeholders, and decide whether to proceed
2. **Planning** — Break work into deliverables, estimate scope, and create a detailed plan
3. **Execution** — Build, test, and track progress toward milestones
4. **Release** — Deploy features to production and verify success
5. **Retrospective** — Capture learnings and drive continuous improvement

## Key Roles

| Role | Responsibility |
|------|-----------------|
| **Project Manager** | Coordinates delivery, manages schedules, risks, and communications |
| **Product Manager** | Defines outcomes, prioritizes the backlog, and measures success metrics |
| **Developers** | Implement features and collaborate on design and quality |
| **QA/Testing** | Validates quality and verifies acceptance criteria |
| **Stakeholders** | Provide inputs, approvals, and strategic direction |

## Key Artifacts

Every project should maintain and reference these key documents:
- **Project Charter / One-pager** — Problem statement, objectives, success metrics, stakeholders, timeline
- **Roadmap and Release Plan** — Phased delivery with milestones
- **Sprint/Iteration Backlog** — Prioritized work items with acceptance criteria
- **Risk Register** — Identified risks with impact, likelihood, owner, and mitigation
- **Retrospective Notes** — Learnings and action items from each phase or sprint

## Communication Cadence

- **Daily:** Team standups (15 min) — progress, blockers, dependencies
- **Weekly:** PM + PdM sync — planning, risks, dependencies
- **Twice-weekly:** Delivery team standups (or as agreed)
- **Monthly:** Stakeholder updates and status reports
- **Ad-hoc:** Escalations and incident communication
